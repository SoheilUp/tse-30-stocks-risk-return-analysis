This project was completed as part of the Advanced Investment course.

Main tasks included:

1. Calculate monthly returns for each stock.
2. Identify best and worst performing stocks.
3. Analyze risk-return relationships.
4. Construct an efficient frontier.
5. Calculate Sharpe Ratios.
6. Estimate stock betas and classify stocks.
